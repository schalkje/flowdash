Test: Prerender First Child Collapse Fix

What This Tests

This test verifies that when using prerendered data, collapsing the first child in a columns container correctly repositions the sibling nodes.

The Bug

  • When the first child adapter collapses, its siblings don't reposition
  • The parent columns container resizes correctly
  • But the remaining nodes stay at their old positions

Expected Behavior

  • First child (adapter) collapses from ~110px wide to ~55px wide
  • Node 3 (ODS) should move LEFT to position ~-22 (was at 23)
  • Node 4 (DWH) should move LEFT to position ~148 (was at 193)

Root Cause

The ZoneManager._prerenderMode flag was not being disabled when a child collapsed, so updateChildPositions() returned early without repositioning siblings.

The Fix

In nodeBaseContainer.js, both collapse() and expand() methods now disable both:

  • parentZone._prerenderMode = false
  • this.parentNode.zoneManager._prerenderMode = false (NEW)
