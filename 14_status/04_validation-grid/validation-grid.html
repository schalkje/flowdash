Validation — full state × mode grid

every state in every mode, side-by-side

Each cell renders a small reference rect with the post-validation indicator on its right edge. The three minimal modes (bar / circle / corner) render the full eight-state vocabulary. The four loud styles only render when state is 'error'; for any other state they emit nothing — that absence is the design, visualized below as dashed cells. The dedicated error (red nose) row right under error highlights how the same error condition switches register entirely when the mode flips to loud.

Cell layout: [ref rect | indicator]. Each cell calls renderValidationIndicators() directly so the grid is a pure pixel comparison — no full dashboard per cell. State→color resolves via the --fd-validation-state-* theme variables — drive the active theme from the global switcher in the top-left of the page (injected by themeManager.js); the grid rebuilds on every theme change so fresh SVGs pick up the new palette. The size selector affects only the four loud styles; the three minimal modes are fixed pixel size by design.
