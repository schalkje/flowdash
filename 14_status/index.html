Status Demos

Status state machine, cascade, auto-collapse

  • Basic state machine
    Cycle nodes through every NodeStatus and observe the parent cascade. Toggle cascade and auto-collapse settings live.
  • Validation errors — red noses
    Pre- and post-validation error indicators, orthogonal to status. Pick a style (Pulse Halo, Rotating Siren, Industrial Tape, Police Line) and toggle pre/post errors per node. Re-tints under every theme.
  • Validation — minimal modes
    Three lightweight baseline modes (bar, circle, corner) that render the full eight-state validation vocabulary (unknown / ready / busy / error / warning / disabled / ok / na), plus a loud-error overlay (pulse / siren / tape / police). Interactive row + 3-mode × 8-state matrix view.
  • Validation — full state × mode grid
    Compact pixel-grid: 8 states × 7 columns (3 baseline validationMode + 4 loud validationLoudError), one screen, theme picker. Includes a dedicated error (red nose) callout row right under error highlighting how the loud overlay reframes the same condition.
  • Validation — minimal modes (pre side)
    Mirror of 03_validation-minimal driving the pre (left) side of each node instead of the post side. Same three baseline modes and same loud-error overlay, attached to the inbound edge. Useful for catching one-sided regressions where a renderer change to post happens to break pre (or vice versa).
