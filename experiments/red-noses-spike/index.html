Red Noses — Validation Error Indicator Design Spike

Five alternative looks for the pre-validation (left side) and post-validation (right side) failure indicators on operations-dashboard nodes. Throwaway exploration — pick the directions worth pursuing.

1. Pulse Halo

animatedfamiliar

The current red nose, evolved: solid circle with an expanding/fading halo ring. Motion grabs attention without changing the existing visual language.

2. Hazard Triangle

iconographicuniversal

Swap the circle for a yellow-bordered warning triangle. Reads as "danger" rather than "status dot" — borrows meaning from road signs and OS-level warning dialogs.

3. Glowing Orb

luminoushigh contrast

Bright radial-gradient orb with a soft red bloom around it. Looks "live" and alarming even when the rest of the dashboard is calm. Works well on dark themes too.

4. Notch Tag

directionalarchitectural

A red chevron-tag that overlaps the node edge and visually points into / out of the node — so the shape itself communicates "input failed" vs. "output failed". No animation; quieter on busy dashboards.

5. Ribbon Label

labelledunambiguous

A short red ribbon with a literal PRE / POST label. Most explicit option — operators can identify the failing side from across the room without hovering. A subtle shake reinforces "something is wrong".

Design spike — throwaway. Each design uses the same "Hello World" node so the indicator is the only variable. Animations are CSS / SMIL and will run live in any modern browser.
