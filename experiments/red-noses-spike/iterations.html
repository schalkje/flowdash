Red Noses — Iterations on the Pulse Halo

Sticking with the Pulse Halo direction (Design 1, kept as baseline at the top). Five new variants below — each pushes a different lever: rhythm, propagation, mechanics, motion, or environment. ← back to the original spike

1. Pulse Halo

baseline — kept
animatedfamiliar

Solid circle + a single expanding halo. The reference point for everything below.

2. Sonar Ping

rhythmstagger

Three halos instead of one, staggered in time. Reads as a radar/sonar ping — feels purposeful and rhythmic rather than a single nervous twitch. The eye locks on faster on a busy dashboard.

3. Heartbeat

rhythmorganic urgency

Same halo, but with a "lub-dub" double-pulse on a long rest — the cadence of a heart monitor. Small ECG trace underlines the metaphor. Feels alive and triggers the "patient in distress" instinct from medical UIs.

4. Shockwave Fracture

mechanicsimpact

The halo is still there, but it leaves radial cracks behind it as it expands — like an impact point. The static cracks remain visible between pulses, so the indicator never "looks calm" even mid-animation.

5. Rotating Siren

motionemergency

Replace the radial halo with a rotating beam — two opposing red cones sweep around the nose like a police beacon. Angular motion catches peripheral vision differently from radial pulses, so this can coexist on a wall with other pulsing UI without blending in.

6. Edge Bleed

propagationinfection

The nose stays put, but its colour leaks along the node border with a fading gradient. The entire node looks "infected" from the failing side. From across the room, you don't see a tiny dot — you see a node that's gone red on the input or output edge.

Iterations on Design 1. Each variant changes one dimension of the baseline pulse: 2 rhythm/stagger, 3 organic cadence, 4 persistent mechanical damage, 5 angular vs. radial motion, 6 propagation across the node body. They are also mixable — e.g. sonar timing + edge bleed, or heartbeat cadence + cracks.
